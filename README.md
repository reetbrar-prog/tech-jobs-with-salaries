Listings come from live postings on public startup job boards; each links to a job page with the full description, salary context for its metro, and a link to the original posting. Stale roles are retired automatically when they disappear from the source board.

Found a dead link or a miscategorized role? [Open an issue](../../issues). The tables are regenerated daily, so edit `scripts/generate_readme.py`, not the tables themselves. See [CONTRIBUTING.md](CONTRIBUTING.md).
